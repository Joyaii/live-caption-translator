# 实时字幕翻译

把 Windows 自带的「实时辅助字幕」识别出的外语，实时翻译成中文悬浮在屏幕上。

主要场景：玩外服游戏时，队友语音是外语，靠它听懂在说什么。

> 不需要虚拟声卡，不需要麦克风，也不需要额外安装语音识别模型 —— 全部复用 Windows 11 自带能力。

## 特性

- **开箱即用**：双击自动拉起 Windows 实时字幕，并把它移到屏幕外，只留翻译结果
- **逐句翻译**：按标点切句，说完就翻，不打断阅读
- **常用语缓存**：`nice shot`、`reloading` 这类高频喊话第二次几乎瞬间出现
- **翻译引擎可切换**：Bing（免注册）或百度（需 appid，失败自动回退）
- **19 种识别语言**：英语（6 种区域）、中文、日语、韩语、法语、德语、意大利语、西班牙语、葡萄牙语、丹麦语
- **外观可调**：拖动移动、拖右下角缩放、多档透明度、字号调节
- **设置持久化**：调好的样子下次打开还在
- **绿色单文件**：打包后 21 MB，不写注册表

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 11 22H2 或更新（Win10 没有实时字幕功能） |
| 架构 | 64 位 |
| 网络 | 能访问 `cn.bing.com` |

## 快速开始

### 方式一：下载可执行文件

从 [Releases](../../releases/latest) 下载 `live-caption-translator-v1.0.zip`，解压后双击 `实时字幕翻译.exe`。

首次运行可能遇到两个提示，都不是病毒：

1. **「Windows 已保护你的电脑」** → 点「更多信息」→「仍要运行」
   （程序没有购买代码签名证书）
2. **杀软报毒** → 加入白名单
   （PyInstaller 打包的程序经常被误报）

不放心可以先传到 [VirusTotal](https://www.virustotal.com/) 查一下。

### 方式二：从源码运行

```bash
pip install uiautomation requests pyttsx3
python caption_translator.py
```

或直接双击 `实时字幕翻译.pyw`。

源码运行启动约 1 秒，打包后的 exe 需要 3 秒（要先解压）。

## 使用

启动后屏幕上方会出现深色悬浮窗：

```
┌────────────────────────────────────────────┐
│ 敌人在B点，现在转移。                        │  ← 中文翻译
│ Enemy spotted on B site, rotate now.        │  ← 英文原文
└────────────────────────────────────────────┘
```

| 操作 | 方法 |
|---|---|
| 移动窗口 | 按住窗口拖动 |
| 调整大小 | 拖右下角 ◢（字号和宽度联动缩放） |
| 打开菜单 | 右键 |
| 菜单内容 | 字号、透明度、识别语言、显示/隐藏原字幕窗、暂停、清空、退出 |

每条字幕独立计时 8 秒，到期单独消失，窗口本身不会隐藏。

## 翻译引擎

默认 Bing，免注册开箱即用。也可切到百度：

| 引擎 | 延迟 | 说明 |
|---|---|---|
| Bing | 1.0-1.4s | 免注册，够用 |
| **百度·大模型** | **~0.5s** | 需 appid，质量最好，推荐 |
| 百度·机器翻译 | ~0.6s | 需 appid，传统 NMT |

实测百度大模型比 Bing 快一倍，译文也更地道：

```
Nice shot.                      Bing: 漂亮的射门    大模型: 干得好，枪法不错
Let us hold this position.      Bing: 让我们保持这个姿势   大模型: 我们守住这个位置
Rotate to A, they are flanking. 大模型: 换点去A，他们正在侧翼包抄
```

### 配置百度

1. 到 [百度翻译开放平台](https://fanyi-api.baidu.com/) 注册并实名认证
2. 控制台创建应用，拿到 **APP ID** 和 **密钥**
3. **大模型翻译要单独开通**（控制台 → 我的服务 → 大模型文本翻译），机器翻译不用
4. 右键悬浮窗 →「百度密钥…」→ 填入 → 保存并启用

百度调用失败（密钥错、超频、余额不足）会自动回退 Bing，不会让字幕空着。错误原因记在 `error.log`。

> 大模型翻译内置了 FPS 语境指令，不加的话 `position` 会被翻成「姿势」、`rotate` 翻成「轮换」。

## 工作原理

```
Windows 实时辅助字幕（系统功能，本地识别）
        ↓  UIAutomation 读取文本
按标点切句 + 稳定性判定（避开识别中间态）
        ↓
Bing 翻译接口（带连接复用和缓存）
        ↓
tkinter 无边框置顶窗口
```

几个关键设计：

- **不按行按句**：实时字幕会把连续多句塞进同一行，句号只是行内分隔符，所以必须按标点切
- **末句延迟确认**：最后一句要稳定 0.9 秒才翻，否则会翻出 `Enemy spotted on B si` 这种半截
- **两级去重**：相似度 + 子串包含，挡住「把前几句拼起来又输出一遍」的重复翻译
- **字幕窗移出屏幕**：把坐标改到 `-32000`，需要时再恢复

## 已知限制

- **独占全屏下悬浮窗会被遮挡** —— 游戏要设成「无边框窗口」或「窗口化全屏」
- **翻译依赖 Bing 接口**，网络受限时可能失败
- **延迟约 2-3 秒**（识别 1 秒 + 翻译 1-2 秒），实时性要求极高的场景不够用
- **未做代码签名**，首次运行会被 SmartScreen 拦截

## 开发

```bash
# 打包
pip install pyinstaller
pyinstaller --onefile --noconsole --icon app.ico --name "实时字幕翻译" caption_translator.py
```

主力文件是 `caption_translator.py`，关键常量都在文件顶部：

| 常量 | 作用 |
|---|---|
| `PAIR_TTL` | 每条字幕停留秒数 |
| `SETTLE_SEC` | 末句稳定判定时间 |
| `ALPHA` | 默认不透明度 |
| `MAX_PAIRS` | 最多同时显示几条 |
